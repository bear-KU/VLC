# VLC
LED を用いた可視光通信の実験用プログラム集．実験には，ESP32 および ESP32s3 を用いている．

## プログラムリスト
### blink
LED を点滅させるだけのプログラム．

### OCC


### read_intensity
LED を受光素子として用いることで，周囲の明るさの強度を取得するプログラム．

### receive_str
LED 同士で行う可視光通信の受信側プログラム．LED で受け取った点滅パターンを解析することで，データを復調する．

### send_str
LED 同士で行う可視光通信の送信側プログラム．データを点滅パターンに変換し，それに従って LED を点滅することでデータを送信する．
